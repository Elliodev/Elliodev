### 🚀 Projet Phare

#### 📋 [Mon Kanban — Application Fullstack](https://github.com/Elliodev/kanban-board)
Application de gestion de tâches développée de bout en bout :
- **Frontend** : **Angular 22**, architecture Standalone, Signals, **Angular CDK** (Drag & Drop), Reactive Forms, Tailwind CSS.
- **Backend & BDD** : API REST en **PHP 8** (PDO, requêtes préparées, sessions sécurisées) et base relationnelle **MySQL** normalisée.
- 🔗 **[Tester l'application en ligne](https://elliodevv-kanban.alwaysdata.net)** · 📂 **[Voir le code source](https://github.com/Elliodev/kanban-board)**
